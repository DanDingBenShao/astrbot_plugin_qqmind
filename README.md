# astrbot_plugin_qqmind · 群聊记忆体

为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 装上一套可配置的群聊记忆管线：**浅层判读门省 token，深层记忆可寻回**。

## 核心思路

群里的消息 99% 不需要 AI 回。qqmind 在主模型之前加一道**浅层判读门**：只喂最近几条群消息，判断"这条是不是在对 AI 说话"——判否只拦主模型（每条判读约几百 token，相比一次完整回复动辄数千 token，拦截即回本），判是才进主模型。判读判"需要动脑"的创作/推理类请求会自动切到思考模型，闲聊走轻快模型。

判否的消息**只拦 LLM、不终结事件链**：其他插件、`/` 命令、AstrBot 内置指令完全不受影响。

## 四档套餐

| 档位 | 读取方式 | 适用场景 | 200 条群聊实测消耗 |
|---|---|---|---|
| 轻量 light | 只回 @ | 安静群 / 省到底 | 最低 |
| 全量 full | 每条判读，判是才回 | 中等活跃群 | ≈77k tok（-26%） |
| 分层 layered | 浅层原文 + 深层群日记 | 重度聊天群 | ≈38k tok（-63%） |
| 高级 advanced | 四轴自选（攒批判读/精确记忆/随机读） | 想精细控成本 | ≈12k tok（-88%） |

对照基线（全量读、无判读门）≈104k tok/200 条。判读次数是第一成本因子。

## 记忆能力

- **群聊**：唤醒、读取、记忆、回复四条轴独立可调；支持按 QQ 号每人一条精确记忆线（默认 4000 token，溢出压成群日记）
- **私聊**：窗口按 token 预算管理（默认 10000），溢出自动压成日记；「还记得吗」「我们昨天聊了什么」都能翻出来（`/日记 最近`、`/日记 关键词`、`/日记 昨天`）
- **群日记入口**：`/群日记 最近|关键词|昨天`，`/群日记 #编号` 看那篇的原话
- **三层日记**：标题+时间（常驻）→ 概要（检索带出）→ 原话全文（`▷` 标记，按需展开）；AI 回忆时概要够答就不展开，省 token
- **日记检索**：标题+时间+标签+摘要，纯 BM25+中文二字组建索引，零 embedding、零额外依赖
- **人设三层**：浅层状态（当前情绪）+ 深层性格（常驻）+ 背景故事篇章库（标题常驻、正文关键词召回）
- **历史数据一键导入**（v0.2.6）：从 DSH/桥接方案迁移，聊天记录批量压成三层日记 + 自动提炼用户画像（进 system prompt）；控制台操作、后台执行、进度可查
- **图片识别**（v0.2.6）：表情包/截图一句话看懂进记忆，GIF 自动抽帧；每日识别预算可控（`vision_budget`）
- **主动私信**（v0.2.6）：休息时段对白名单好友主动找话聊（带记忆接上次话头）；每人每天限 1 条、连续不回应冷却 7 天（`proactive_friends` 空=关闭）
- **分群账本**（v0.2.7）：`/账单` 群里=本群数据+全网总量，私聊=全网；token 与读/回/拦全部按群分账落盘
- **跨群共享记忆**（v0.2.7，默认关）：开启后 A 群可按需寻回 B 群（白名单内）的日记，`share_memory_across_groups`

## 护栏

每日 token 预算熔断（烧完自动降级只@）· 每群回复频率上限（兼 QQ 风控保护）· @全体忽略 · bot 互怼拦截 · 判读连续失败自动降级轻量 · 主动私信多重护栏（白名单/每日上限/冷却/时段限制）

## 安装

在 AstrBot WebUI 的插件市场搜索 `qqmind`，或直接从仓库安装：

```
https://github.com/DanDingBenShao/astrbot_plugin_qqmind
```

零第三方依赖（纯 Python 标准库 + astrbot.api），装上即可用。

## 快速上手

1. 装好后把机器人拉进群，默认轻量档：只回 @ 消息
2. 在 WebUI 插件配置里改 `group_preset` 为 `full`（逐条判读）或 `layered`（分层记忆）
3. 有创作/推理需求（写诗、解题）建议配置 `judge_model`（如 deepseek-chat，判读快且省）与 `think_model`（如 deepseek-reasoner，判读判「要动脑」的当轮自动切换）
4. 控制台页面（插件详情页）可看今日账本、浏览日记、管人设

## 配置要点

常用键都有中文说明，几个关键的：

- `group_preset`：套餐档位（light/full/layered/advanced）
- `judge_scope`：监控期外是否也判读（烧判读调用，慎开）
- `daily_token_budget`：每日预算，0 不限
- `reply_rate_per_min`：每群每分钟回复上限（默认 6，兼风控保护）
- `allowed_groups`：群白名单，空=不限

## 已知边界

- 全量档逐条判读在极活跃群可能判读开销超过回复开销（bench 数据见上表），重度群建议 layered/advanced
- 极端长道具/长文场景与生成端无关，本插件只管记忆与判读，不干预生成
